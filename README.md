Welcome to the ultimate Pokédex Battle experience!
This isn’t just another fan-made project—it’s a fully interactive, fast-paced, and visually engaging Pokémon battle app built with React and powered by Node.js.

Features
	•	Dynamic Pokémon Selection
Choose from a wide range of Pokémon with authentic names, types, and stats pulled from the Pokédex. Each selection feels like flipping through your very own digital Pokédex!
	•	Epic Turn-Based Battles
Engage in classic Pokémon-style battles with intuitive attack mechanics. Every click triggers real-time stat changes and animations that make each match feel intense and unpredictable.
	•	Responsive UI
Styled with custom CSS, the interface is sleek, mobile-friendly, and ready to impress on any screen.
	•	Built with Modern Tech
	•	Frontend: React
	•	Backend: Node.js + Express
	•	Styling: Custom CSS
	•	Static content delivery via Express static middleware
	•	Single Page Application
Everything is neatly bundled in one smooth-flowing interface—no page reloads, no waiting.
	•	Deploy-Ready
Optimized with a production-ready build system and setup to easily deploy on platforms like Replit, Glitch, or even GitHub Pages with backend tweaks.
